# Noodle UI и Noodle Script

Нативные приложения Noodle.OS пишутся на двух связанных языках, которые живут в файлах `.nui` и `.ns`
(синтаксис один и тот же, расширения — для удобства):

* **Noodle UI** — описание интерфейса: экраны и дерево элементов;
* **Noodle Script** — код приложения: состояние, функции, циклы, коллекции.

Исходники компилируются в **байткод** (`main.nbc`) и исполняются нативным рантаймом: виртуальная машина +
собственная раскладка + программный растеризатор. Ни HTML, ни CSS, ни JavaScript, ни WebView здесь нет.

```nui
app "Counter"

state count = 0 persist              // persist — значение переживает перезапуск

fn inc() { count += 1; vibrate(15) }

screen main {
  column grow center gap=32 {
    text "{count}" size=120 weight=200
    button "+" primary on=inc
  }
}
```

## Файл верхнего уровня

| Конструкция | Смысл |
|---|---|
| `app "Название"` | необязательно, имя для отладки |
| `state имя = выражение [persist]` | глобальное состояние. После его изменения интерфейс перестраивается сам. `persist` сохраняет значение (JSON) между запусками |
| `let имя = выражение` | глобальное значение (вычисляется один раз при старте) |
| `fn имя(параметры) { … }` | функция |
| `screen имя { элементы }` | экран. Стартовый — `main` (или первый объявленный) |

Файлов может быть много: компилятор объединяет все `.nui`/`.ns` проекта (файл из `entry` — первым).
Порядок объявлений не важен.

## Noodle Script

Синтаксис в духе Kotlin/Swift. Оператор заканчивается переводом строки или `;`. Строка продолжается на следующей,
если заканчивается оператором, запятой или внутри `()`/`[]`.

```nui
fn total(items) {
  let sum = 0
  for it in items { sum += it.price * it.qty }
  return sum
}
```

**Операторы:** `let x = e` · `x = e` · `x += e` (`-= *= /= %=`) · `a.b = e` · `a[i] = e` · `if / else if / else` ·
`while` · `for x in список` · `for i, x in список` · `for k, v in словарь` · `return` · `break` · `continue`.

**Выражения:**

| | |
|---|---|
| литералы | `42`, `3.14`, `0xFF`, `"строка {с выражением}"`, `'сырая {строка}'`, `true`, `false`, `null` |
| списки | `[1, 2, 3]`, `[...a, x]`, `a[0]`, `a[-1]`, `a.len` |
| словари | `{name: "Аня", "ключ": 1}`, `{...m, extra: 2}`, `m.name`, `m["name"]` |
| функции | `fn(a, b) { … }`, `fn(x) => x * 2` — замыкания видят и меняют внешние переменные |
| операторы | `+ - * / %`, `== != < <= > >=`, `&& \|\| !`, `a ?? b` (если `a` — `null`), `c ? x : y`, диапазон `0..10` |
| вызовы | `f(x)`, `список.метод(x)` — встроенные функции можно вызывать как методы первого аргумента |

Типы: `number`, `string`, `bool`, `list`, `map`, `function`, `null`. «Ложь» — это `null`, `false`, `0`, `""`.
Списки и словари — ссылки (как в JS). Строка с `{…}` — интерполяция; литеральная скобка — `\{`.

Ошибки видны сразу: компилятор сообщает файл, строку и колонку (`неизвестное имя «x»`, `неизвестный элемент «blah»`),
ошибки выполнения идут в консоль с трассировкой, а приложение продолжает работать. Бесконечный цикл
останавливается через ~30 млн операций (не зависание интерфейса).

### Встроенные функции

| Группа | Функции |
|---|---|
| общие | `print str repr num int bool type len json parse_json copy` |
| числа | `abs floor ceil round(x, знаков) sqrt pow sin cos min max clamp random() random(n) random(a, b)` |
| строки | `upper lower trim split(s, sep) join(list, sep) replace starts_with ends_with repeat pad_start(s, n, ch) pad_end fixed(n, знаков) index_of contains slice(s, a, b)` |
| списки | `push pop insert(list, i, v) remove(list, i) concat reverse sort(list[, cmp]) sort_by(list, fn) map filter find find_index reduce(list, init, fn) any all sum slice range(a, b) list` |
| словари | `keys values has delete(map, key) contains` |
| время | `now()` (мс), `time_parts(ms)` → `{year, month, day, hour, minute, second, weekday}` |
| таймеры | `after(мс, fn)`, `every(мс, fn)` → id, `cancel(id)` |
| система | `goto("экран")`, `back()`, `toast(текст)`, `vibrate(мс)`, `exit()`, `save(ключ, значение)`, `load(ключ, по_умолчанию)` |

`sort`, `reverse`, `map`, `filter`, `slice`, `concat` возвращают **новый** список; `push`, `pop`, `insert`, `remove` меняют на месте.

### Хуки

* `fn on_back() { … }` — системная кнопка «Назад»: верните `true`, если обработали сами (иначе приложение вернётся
  на предыдущий экран или закроется).

## Noodle UI

Элемент пишется в одну строку: `тип "текст" атрибут=значение флаг { дети }`.

```nui
screen main {
  bar "Список" { button "+" ghost on=add }
  column grow padding=16 gap=12 {
    input bind=draft placeholder="Новая задача" on_submit=add
    scroll grow {
      if items.len == 0 { text "Пока пусто" dim center padding=40 }
      each items as item, i {
        row gap=12 padding=12 border {
          toggle bind=item.done
          text "{item.text}" grow dim={item.done}
          button "×" ghost on={ items.remove(i) }
        }
      }
    }
  }
}
```

### Элементы

| Элемент | Назначение |
|---|---|
| `column`, `row`, `box` | контейнеры (`box` — то же, что `column`) |
| `scroll` | прокручиваемый контейнер (колесо, перетаскивание) |
| `text "…"` | текст (переносится по ширине) |
| `button "…"` | кнопка |
| `input` | однострочное поле; `area` — многострочное |
| `toggle` | переключатель; `slider` — ползунок |
| `bar "Заголовок"` | верхняя панель; на втором и далее экранах сама показывает кнопку «назад» |
| `progress`, `divider`, `spacer`, `image` | индикатор (`value={0..1}`), линия, растяжимый отступ, заглушка |
| `if условие { … } else { … }` | условный блок |
| `each список as элемент[, индекс] { … }` | цикл (также `for элемент in список { … }`) |
| `let имя = выражение` | локальная переменная в блоке |

### Атрибуты

| | |
|---|---|
| размеры и отступы | `padding` `px` `py` `pt` `pr` `pb` `pl` `gap` `width` `height` (число или `"50%"`) `min_height` |
| раскладка | `grow` (доля свободного места; флаг = 1) · `align=start\|center\|end\|stretch` · `justify=start\|center\|end\|between` · `center` (в контейнере — центрировать содержимое, в `text` — текст) |
| вид | `bg` `color` (`"#RRGGBB"`, `white`, `black`, `gray`, `red`, `green`, `blue`, `yellow`) · `radius` · `border` |
| текст | `size` · `weight` (300/400/600) · `bold` · `dim` · `caps` · `mono` |
| `button` | `on=функция` или `on={ операторы }` · `primary` · `ghost` · `full` · `disabled={условие}` |
| `input`, `area` | `bind=переменная` (или `a.b`, `a[i].c`) · `placeholder` · `type=number\|password` · `on_submit=…` · `on={…}` (при изменении) |
| `toggle`, `slider` | `bind=…` · для `slider` `min max step` |
| любой | `key="…"` — стабильный идентификатор, если элементы меняют порядок |

Значение атрибута: число (`gap=8`), строка с интерполяцией (`bg="#111"`), имя (`on=inc`), выражение или операторы в
фигурных скобках (`disabled={n > 5}`, `on={ n += 1; save("n", n) }`), флаг без значения (`dim`).

`bind=x` двусторонний: поле показывает `x` и записывает в него ввод. В `type=number` приходит число (или `null`, если пусто).

### Как перестраивается интерфейс

Любое событие (нажатие, ввод, таймер) вызывает ваш код; после него экран пересобирается из состояния целиком, затем
раскладка и отрисовка. Фокус, позиция курсора и прокрутка сохраняются по «пути» элемента (или по `key`). Полная
пересборка списка из 300 строк занимает ~3,5 мс (см. «Производительность» в `docs/RUNTIME.md`).

## Клавиатура и указатель

Мышь/касание, колесо и перетаскивание в `scroll`, ввод текста (в т.ч. кириллица, экранная клавиатура в Studio на телефоне),
стрелки, `Home/End`, `Backspace/Delete`, `Enter` (в `area` — перенос строки, в `input` — `on_submit`), `Tab` (следующее поле),
`Esc` (снять фокус / «Назад»).

## Чего пока нет

Изображений (`image` рисует рамку-заглушку), сети, выделения текста и буфера обмена, анимаций, нескольких окон.
Список растёт — формат байткода версионирован (`NBC1`).
