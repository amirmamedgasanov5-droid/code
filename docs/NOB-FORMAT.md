# Формат пакета `.nob` (Noodle Bundle) v1

`.nob` — установочный файл приложения Noodle.OS (как `.apk` для Android). Это обычный ZIP-архив — его открывает любой
архиватор, поэтому пакет можно разобрать, изменить и собрать заново.

> Расширение `.nob` выбрано как короткое и нигде не занятое. Если у вас оно окажется занято, смените константу `NOB_EXT`
> в `studio/js/nob.js` — больше нигде оно не зашито.

## Структура

```
META/NOB              "noodle-bundle 1"   магическая строка, всегда первая запись
manifest.json         манифест приложения
app/main.nbc          скомпилированный байткод Noodle (стек noodle) — то, что исполняет рантайм
app/…                 исходники (.nui/.ns), иконка и прочие файлы проекта — чтобы пакет можно было открыть и править
META/hashes.json      SHA-256 каждого файла пакета
META/signature.json   ECDSA P-256 подпись над байтами hashes.json + публичный ключ
```

* Для стека `noodle` байткод **обязателен** (`buildNob` без него не соберёт пакет). Рантайм исполняет `app/main.nbc`;
  исходники лежат рядом для редактирования (Studio при открытии `.nob` берёт исходники, а байткод пересобирает).
* Сборка воспроизводима: порядок файлов отсортирован, время в ZIP фиксировано (1980-01-01). Одинаковые входы дают
  одинаковые байты (кроме самой подписи — ECDSA вероятностна).
* Сжатие — deflate, если оно уменьшает файл; иначе stored.

## Байткод `NBC1`

`app/main.nbc` = 4 байта `NBC1` + сериализованная программа (константы, функции, имена глобальных, таблица экранов,
список `persist`-состояний). Формат создаёт и читает `noodle-core` (`Program::to_bytes` / `from_bytes`). Версия в сигнатуре:
несовместимые изменения получат новую (`NBC2`), рантайм отвергает чужие версии.

## Подпись и проверка

Установщик обязан:

1. Прочитать `META/signature.json`, проверить подпись ECDSA-P256/SHA-256 над **точными байтами** `META/hashes.json`.
2. Сверить SHA-256 каждого файла из `hashes.json` с содержимым архива.
3. Отклонить пакет, если в архиве есть файл вне `META/`, не перечисленный в `hashes.json`.
4. Отклонить пакет с путями вида `../x`, `/abs`, `a\b`, `a//b` (защита от zip-slip).
5. Проверить манифест.

`keyId` — первые 16 hex-символов SHA-256 от `{"x":…,"y":…}` публичного ключа. Обновление принимается, только если
`keyId` совпадает с ключом установленной версии.

Реализация — `readNob()` в `studio/js/nob.js` (проверка в браузере и Node, `nob verify`); покрыта тестами: подмена файла и
байткода, добавленный файл, подмена хэшей, zip-slip, мусор вместо пакета. Нативный `noodle run` загружает `.nob`, но подпись
не проверяет — это задача установщика ОС.

## manifest.json

| Поле | Тип | Описание |
|---|---|---|
| `format` | `1` | версия формата |
| `id` | строка | `com.company.app`: строчные латинские буквы, цифры, `_`, минимум 2 сегмента, без зарезервированных слов Java (`native`, `new`…) — для совместимости с Android-стеками |
| `name` | строка | 1–40 символов |
| `version` | строка | семвер `1.2.3` |
| `versionCode` | целое ≥ 1 | растёт с каждым релизом |
| `stack` | `noodle` \| `web` \| `kotlin` \| `flutter` \| `swift` | по умолчанию `noodle` |
| `entry` | путь | `.nui` для `noodle`, `.html` для `web`; для Kotlin/Flutter/Swift не нужен |
| `icon` | путь | `.svg` или `.png` внутри проекта |
| `permissions` | массив | `vibrate`, `network` (только `web`) |
| `window.orientation` | `portrait` \| `landscape` \| `auto` | |
| `window.background` | `#RRGGBB` | цвет фона и системных панелей |
| `window.statusBar` | `light` \| `dark` | цвет значков статус-бара |

Пакет `.nob` собирают стеки `noodle` и `web`. Kotlin/Flutter/Swift дают APK/IPA своими тулчейнами (`docs/STACKS.md`).

## Установка в ОС (референс — симулятор в Studio)

1. Проверка подписи и хэшей → иначе отказ.
2. Пакет сохраняется целиком; иконка и имя берутся из манифеста.
3. Запуск: рантайм создаёт `App` из `app/main.nbc`, подаёт события и показывает кадры; данные приложения (`persist`, `save/load`)
   хранятся отдельно для каждого `id`.

## Приложение: веб-стек (режим совместимости)

Для `stack: "web"` вместо байткода пакет содержит HTML/CSS/JS, а приложение получает объект `window.noodle`:

```js
noodle.storage.get(key, fallback) / set / remove / clear / keys
noodle.toast("текст"); noodle.vibrate(30)   // нужно разрешение "vibrate"
noodle.onBack(() => true)                    // true — «Назад» обработано приложением
noodle.exit(); noodle.saveFile(name, data, mime); noodle.platform; noodle.app
```

Без разрешения `network` запросы наружу блокируются CSP. Веб-приложения исполняются в песочнице WebView/iframe и не используют
нативный рантайм.
