# Формат пакета `.nob` (Noodle Bundle) v1

`.nob` — установочный файл приложения Noodle.OS, как `.apk` для Android. Это обычный ZIP-архив
(его открывает любой архиватор), поэтому пакет можно разобрать, изменить и собрать заново.

> Расширение `.nob` выбрано как короткое и нигде не занятое в экосистеме Android/desktop. Если у вас
> оно окажется занято, смените константу `NOB_EXT` в `studio/js/nob.js` — больше нигде оно не зашито.

## Структура

```
META/NOB              "noodle-bundle 1"   магическая строка, всегда первая запись
manifest.json         манифест приложения
app/…                 файлы приложения (исходники/ресурсы — как в проекте)
META/hashes.json      SHA-256 каждого файла пакета
META/signature.json   ECDSA P-256 подпись над байтами hashes.json + публичный ключ
```

* Сборка **воспроизводима**: порядок файлов отсортирован, время в ZIP фиксировано (1980-01-01).
  Одинаковые входы дают одинаковые байты (кроме самой подписи — ECDSA вероятностна).
* Сжатие — deflate, если оно уменьшает файл; иначе stored.

## Подпись и проверка

Установщик обязан:

1. Прочитать `META/signature.json`, проверить подпись ECDSA-P256/SHA-256 над **точными байтами** `META/hashes.json`.
2. Сверить SHA-256 каждого файла из `hashes.json` с содержимым архива.
3. Отклонить пакет, если в архиве есть файл вне `META/`, не перечисленный в `hashes.json`.
4. Отклонить пакет с путями вида `../x`, `/abs`, `a\b`, `a//b` (защита от zip-slip).
5. Проверить манифест.

`keyId` — первые 16 hex-символов SHA-256 от `{"x":…,"y":…}` публичного ключа. Обновление приложения
принимается, только если `keyId` совпадает с ключом установленной версии.

Все эти проверки реализованы в `readNob()` (`studio/js/nob.js`) и покрыты тестами `tests/core.test.mjs`
(подмена файла, добавленный файл, подмена хэшей, zip-slip, мусор вместо пакета).

## manifest.json

| Поле | Тип | Описание |
|---|---|---|
| `format` | `1` | версия формата |
| `id` | строка | `com.company.app`: строчные латинские буквы, цифры, `_`, минимум 2 сегмента, без зарезервированных слов Java. Становится `applicationId` в APK |
| `name` | строка | 1–40 символов |
| `version` | строка | семвер `1.2.3` |
| `versionCode` | целое ≥ 1 | растёт с каждым релизом |
| `stack` | `web` \| `nui` \| `kotlin` \| `flutter` \| `swift` | по умолчанию `web` |
| `entry` | путь | `.html` для `web`, `.nui` для `nui`; для нативных стеков не нужен |
| `icon` | путь | `.svg` или `.png` внутри проекта |
| `permissions` | массив | `network`, `vibrate` |
| `window.orientation` | `portrait` \| `landscape` \| `auto` | |
| `window.background` | `#RRGGBB` | цвет фона/системных панелей |
| `window.statusBar` | `light` \| `dark` | цвет значков статус-бара |

### Разрешения

* `network` — разрешает `fetch`/XHR/WebSocket к внешним адресам. Без него Studio и Android-обёртка
  добавляют в страницу `Content-Security-Policy: connect-src …` (браузер реально блокирует запросы), а в APK
  не объявляется `INTERNET`.
* `vibrate` — `noodle.vibrate(ms)`; в Android добавляется `VIBRATE`.

## Рантайм: объект `noodle`

Подключается автоматически (в Studio, в симуляторе и в APK) — отдельно подключать ничего не нужно.

```js
noodle.storage.get(key, fallback)   // JSON-значения; переживают перезапуск
noodle.storage.set(key, value)
noodle.storage.remove(key); noodle.storage.clear(); noodle.storage.keys()
noodle.toast("текст")
noodle.vibrate(30)                  // нужно разрешение "vibrate"
noodle.onBack(() => true)           // true — «Назад» обработано приложением; иначе приложение закроется
noodle.exit()
noodle.saveFile("a.txt", "данные", "text/plain")   // скачивание / «Загрузки» на Android
noodle.platform                     // "preview" | "android" | "web"
noodle.app                          // { id, name, version }
```

В превью обычный `localStorage` тоже работает (подменён на хранилище Studio), но предпочтителен `noodle.storage`.

## Как ОС ставит пакет (референс — симулятор в Studio)

1. `readNob()` проверяет подпись/хэши → иначе отказ.
2. Пакет сохраняется целиком; иконка и имя берутся из манифеста.
3. Запуск: файлы читаются из пакета, приложение исполняется в песочнице без доступа к данным ОС и других приложений.
