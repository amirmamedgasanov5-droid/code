# Firebase: правила, администратор, коллекции

Проект: `ar-ridwan-c32fc` (основной). Правила нужно **опубликовать вручную** — сайт сам их не применяет.

## 1. Опубликовать правила Firestore
1. Firebase Console → проект `ar-ridwan-c32fc` → **Firestore Database → Rules**.
2. Скопировать содержимое файла `firestore.rules` целиком → **Publish**.

(Либо из терминала: `npm i -g firebase-tools && firebase login && firebase deploy --only firestore:rules,database`.)

## 2. Правила Realtime Database (игры и рисовалка)
Console → **Realtime Database → Rules** → вставить `database.rules.json` → Publish.

## 3. Администратор
- Главный администратор: **amirmamedgasanov5@gmail.com** (в правилах и в `src/utils/roles.ts`).
- Он видит и может менять всё; в сайте у него появляются разделы **Bannerlər** и **İdarə paneli**.
- Чтобы сделать администратором или учителем кого-то ещё: İdarə paneli → выбрать роль у пользователя.
- Регистрация: все новые аккаунты создаются как «Tələbə». Тот, кто выбрал «Müəllim», попадает в список **Müəllim sorğuları**, и права учителя включаются после подтверждения администратором.

> Важно: аккаунт с этим email должен уже существовать (создайте/войдите до публикации правил), иначе кто-то другой может зарегистрировать этот адрес первым.

## Родители
- Родитель регистрируется сам: «Qeydiyyat → Valideyn», вводит одноразовый **код** и придумывает **свой пароль**. Ученик пароля не знает и в портал войти не может.
- Код выдаёт администратор: İdarə paneli → у ученика кнопка **«Valideyn kodu»**. Код работает один раз. Для второго родителя создайте второй код.
- Родитель видит только кабинет своего ребёнка и настройки. Ученикам раздел «Valideyn Portalı» недоступен.
- Старый вход по PIN (в том числе стандартный «1234») полностью удалён.
- Забыли пароль: на странице входа «Şifrəni unutdum» или кнопка «Şifrə sıfırla» в панели администратора.

## 4. Коллекции
Firestore создаёт коллекции при первой записи. Чтобы не ждать, зайдите на сайт администратором →
**İdarə paneli → «İlkin məlumatları yarat»** — создаст `banners` (приветственный баннер) и `school_settings/main`.

## 5. Кто что может
| | Ученик | Учитель | Администратор |
|---|---|---|---|
| Баннеры | видит | создаёт, меняет и удаляет свои | всё |
| Объявления, задания, журнал, расписание | видит | создаёт и меняет | всё |
| Роли пользователей | — | — | меняет |
| Блокировка учеников | — | да | да |

## Что правила не закрывают
- Библиотека (`books`) лежит в другом Firebase-проекте (`madrasa-lms-68dd5`) и использует его собственные правила.
- Родительский портал входит анонимно, поэтому для него чтение данных открыто любому вошедшему.
- Правильные ответы тестов хранятся в самих заданиях. Чтобы их нельзя было достать, проверку ответов нужно перенести на сервер.
