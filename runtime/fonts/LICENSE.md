# Шрифты, встроенные в рантайм Noodle

Подмножества (латиница, кириллица, стрелки и базовые символы) для компактности.

* **Inter** (Light, Regular, SemiBold) — SIL Open Font License 1.1, © The Inter Project Authors (https://github.com/rsms/inter)
* **JetBrains Mono** (Regular) — SIL Open Font License 1.1, © JetBrains s.r.o. (https://github.com/JetBrains/JetBrainsMono)

Подмножества созданы утилитой `pyftsubset` (fontTools) без изменения контуров глифов.
