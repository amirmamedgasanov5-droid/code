# Хидая · هداية

Сайт Telegram-канала **[@hidaya_islam1](https://t.me/hidaya_islam1)** — канала для сестёр с тафсиром ас-Саади,
хадисами, дуа и ежедневными напоминаниями на русском языке.

Next.js 15 (статический экспорт) · TypeScript · Tailwind CSS 4 · Framer Motion · Lucide.
Шрифты ставятся из npm (`@fontsource`), внешних запросов при просмотре нет.

## Запуск

```bash
npm install
npm run dev          # разработка
npm run build        # синхронизация с Telegram + сборка в ./out
npm run start        # посмотреть ./out локально
```

Для публикации достаточно залить папку `out/` на любой статический хостинг. Укажите адрес сайта для OG-тегов и sitemap:

```bash
NEXT_PUBLIC_SITE_URL=https://ваш-домен npm run build
```

## Библиотека знаний

Тексты не пишутся вручную: `scripts/build-library.mjs` раскладывает открытые наборы данных по файлам в `public/library` (в репозитории лежит готовый результат, ~34 МБ).

| Раздел | Что внутри | Источник |
| --- | --- | --- |
| Коран | 114 сур, 6 236 аятов, арабский текст, перевод Э. Кулиева, транслитерация, 30 джузов | пакет `quran-cloud` (quranenc.com, Tanzil), CC BY-SA 4.0 |
| Хадисы | Бухари (7 502), Муслим (2 719), Абу Дауд (4 602) — русский и арабский, оценки | `hadith-api` (fawazahmed0) |
| Дуа | Хисн аль-Муслим: 298 текстов, арабский и транслитерация | `@kazishariar/hisnul-muslim-data` |
| Публикации | вся история текстовых постов канала (с июня 2025) | Telegram `t.me/s/hidaya_islam1` |

В источниках русский перевод есть не для всех хадисов Муслима и Абу Дауда — показаны только переведённые. Битые символы U+FFFD из источников убираются при сборке.
Есть: поиск по Корану и по каждому сборнику хадисов, переход по номеру (`2:255`), закладки (аяты, хадисы, дуа, публикации), «продолжить чтение», «аят дня» и «хадис дня», ссылки из публикаций с тафсиром на аят.

```bash
NODE_USE_ENV_PROXY=1 node scripts/build-library.mjs   # пересобрать библиотеку (нужна сеть)
```

## Автообновление публикаций

`scripts/sync-telegram.mjs` читает публичную ленту канала и **дописывает** новые посты в `data/channel.json` (правки и удаления тоже учитываются).

- Раз в час это делает GitHub Actions (`.github/workflows/sync-channel.yml`): коммитит файл при изменениях, а хостинг (Vercel, Netlify, Cloudflare Pages), подключённый к репозиторию, сам пересобирает сайт.
- Вручную: `npm run sync`; вся история: `SYNC_PAGES=400 npm run sync`. Каждая сборка (`npm run build`) тоже сначала обновляет данные.
- Рубрика и короткое название конкретной публикации, а также «Избранное» настраиваются в `data/curation.ts`.

## Дизайн и структура

Интерфейс сделан как нативное приложение iOS: большие заголовки, сгруппированные списки, «жидкое стекло», сегментированные контролы, переключатели, листы со свайпом, свайп-назад и пружинные анимации. Светлая и тёмная темы переключаются автоматически.

- **Таб-бар**: на телефоне — плавающая стеклянная капсула снизу, на планшете и шире — вертикальная сбоку (как на iPad).
- **Вкладки**: Главная, Библиотека (стек экранов с переходами), Лента, Закладки, Сегодня (дата по хиджре, время намаза, кибла, тасбих). Страница «Канал» открывается с главной.

| Путь | Что там |
| --- | --- |
| `app/` | layout, метаданные, `/library/posts*.json`, robots, sitemap |
| `components/` | `Shell`, `TabBar`, `Screen`, `Sheet`, `Reader`, `library/*`, `views/*` |
| `lib/` | данные, рубрики, время намаза, хиджра, загрузчики JSON |
| `data/` | `channel.json` (все публикации), `curation.ts` |
| `public/library/` | Коран, хадисы, Хисн аль-Муслим |

Цвета — системные цвета iOS в `app/globals.css`. Шрифты: SF Pro на устройствах Apple, Inter на остальных, Amiri и Amiri Quran для арабского.
