# İsnad Mədrəsəsi — onlayn mədrəsə platforması

React 19 + Vite + Tailwind 4 + Firebase.

```
npm install
npm run dev      # lokal
npm run build    # dist/
npm run lint     # tsc --noEmit
```

Firebase: `FIREBASE_SETUP.md`, `firestore.rules`, `database.rules.json`.
Loqo: `public/logo.png` (şəffaf fon). Rənglər və hərəkət tokenləri: `index.css` (`@theme`).

Деплой на EdgeOne Pages: `release/isnad-edgeone.zip` (index.html в корне архива) — «Upload» в EdgeOne Pages.
Платформа полностью на русском языке.
