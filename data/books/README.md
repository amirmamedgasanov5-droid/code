# Тексты книг для «Пути знаний»

Положите сюда файлы `<id>.md`, и после `npm run build` книга откроется в приложении («читать здесь»).
`<id>` берётся из списка в `components/library/Books.tsx` (например, `usul3`, `tawhid`, `riyad`).

Формат:

```markdown
---
id: usul3
title: Аль-Усуль ас-Саляса («Три основы»)
author: Мухаммад ибн Абдуль-Ваххаб
---

# Название главы

Абзацы разделяются пустой строкой.

# Следующая глава
```

Главы — строки, начинающиеся с `# `. Без заголовков текст автоматически делится на части.
Добавляйте только тексты, на публикацию которых у вас есть право (общественное достояние или разрешение переводчика и издателя).
Тексты здесь ни разу не сочиняются и не правятся сайтом.
